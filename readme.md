# DynaWeb: Model-Based Reinforcement Learning of Web Agents

Official implementation of **EMNLP 2026** paper **DynaWeb**, a model-based reinforcement learning framework that trains web agents with imagined rollouts generated by a learned web world model. DynaWeb supports GRPO, DAPO, and GSPO, and can interleave expert trajectories with model-generated experience for stable policy optimization.

This repository is built on [rLLM](https://github.com/rllm-org/rllm) and supports its v0.2 interface.

## Setup

Follow the [rLLM installation guide](https://github.com/rllm-org/rllm) to configure the environment. Before training:

1. Launch a vLLM server for the world model.
2. Configure the model paths, world-model endpoint, output directory, and experiment-tracking credentials in the scripts.
3. Generate the required data:

```bash
bash world/run.sh
```

## Training

GRPO:

```bash
bash scripts/agent/webarena/run_webarena_world_model.sh
```

DAPO:

```bash
bash scripts/agent/webarena/run_webarena_world_model_dapo.sh
```

GSPO:

```bash
bash scripts/agent/webarena/gspo.sh
```

## Expert Trajectory Interleaving

Gold-standard expert trajectories can be injected into rollout groups through:

```bash
STANDARD_ANSWER_K=${STANDARD_ANSWER_K:-1}
```

At the configured interval, one trajectory in an eligible rollout group is replaced by a randomly sampled expert trajectory with a successful terminal reward. The paper uses a training mixture containing 40% real expert trajectories.


## Multi-Node Training

After generating the data and launching the world-model service, use `multi_node_gspo.sh` or `multi_node_grpo.sh`. A practical starting allocation is one world-model node for every one or two policy-training nodes. Update the service URL, distributed settings, checkpoint frequency, and evaluation frequency before launching.
